# SAP FICO Excel Simulation

## Overview

This project is an Excel-based SAP FICO simulation developed to demonstrate core Financial Accounting workflows using Microsoft Excel, formulas, structured tables, and VBA automation.

The project simulates how accounting transactions can be entered, validated, posted, and reflected across financial reports.

**Company:** Emirates Trading LLC  
**Company Code:** ET01  
**Currency:** AED  
**Fiscal Year:** 2026  
**Accounting Basis:** Accrual

---

## Project Objectives

- Simulate SAP FI transaction posting in Excel
- Automate accounting document creation using VBA
- Maintain a structured Chart of Accounts
- Generate journal entries automatically
- Track General Ledger balances
- Generate Trial Balance
- Simulate Accounts Receivable and Accounts Payable
- Generate Profit & Loss and Balance Sheet reports
- Analyze expenses by Cost Center
- Provide a management dashboard
